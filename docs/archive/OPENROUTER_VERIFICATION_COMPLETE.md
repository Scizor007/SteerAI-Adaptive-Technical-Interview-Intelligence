## Known Issues

### JSON Parsing Failures (Non-Critical)

**Issue:** Some evaluation responses fail JSON parsing
```
Failed to parse LLM response as JSON: Expecting value: line 3 column 16
Raw Output: {"accuracy": 2, "reasoning": , "depth": 0...
```

**Root Cause:** `meta-llama/llama-3.2-3b-instruct` sometimes generates incomplete JSON

**Impact:** 
- Some evaluations fall back to "unavailable"
- Interview continues correctly
- Does not affect questions or feedback

**Mitigation:**
1. Fallback detection catches these cases
2. Evaluations marked as unavailable (not stored)
3. Interview progresses without issues
4. Final feedback generated successfully

**Future Fix (Optional):**
- Use more reliable model (e.g., `google/gemini-flash-1.5` on paid tier)
- Add JSON repair logic in parser
- Increase retry count for evaluations
