## Troubleshooting

### If verification fails with "Provider is None"

**Cause:** API key still has placeholder format or is missing

**Fix:**
1. Check `backend/.env` has real key (not `<YOUR_OPENROUTER_API_KEY>`)
2. Key should start with `sk-or-v1-`
3. Restart verification script

### If verification fails with HTTP 401

**Cause:** Invalid API key

**Fix:**
1. Verify key is correct (no extra spaces)
2. Generate new key at https://openrouter.ai/keys
3. Update `.env` and retry

### If verification fails with HTTP 429

**Cause:** Rate limit exceeded (unlikely on free tier)

**Fix:**
1. Wait 60 seconds
2. Retry verification
3. Consider using paid plan if testing heavily

### If verification fails with "no choices"

**Cause:** Model may be unavailable or response format issue

**Fix:**
1. Check OpenRouter status: https://openrouter.ai/status
2. Try different model in `.env`:
   - `google/gemini-2.0-flash-exp:free`
   - `meta-llama/llama-3.1-8b-instruct:free`
   - `microsoft/phi-3-mini-128k-instruct:free`
